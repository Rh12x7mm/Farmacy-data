# Farmacy-data
база данных сети аптек в России(проект)


Проект был разработан:


velogxx(проджект менеджер)


mqipn(заместитель пм)


erRinor(exel отчет)


Rh12x7mm(sql код)


Цель проекта - создание базы данных аптечной сети, которая позволяет хранить информацию о лекарственных препаратах, производителях, действующих веществах, чеках оплаты, показаниях к применению и филиалах аптек.
