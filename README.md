# Farmacy-data
база данных сети аптек в России(проект)


Проект был разработан:


velogxx(проджект менеджер)


mqipn(заместитель пм)


erRinor(exel отчет, сбор данных)


Rh12x7mm(sql код)


Цель проекта - создание базы данных аптечной сети, которая позволяет хранить информацию о лекарственных препаратах, производителях, действующих веществах, чеках оплаты, показаниях к применению и филиалах аптек.

в папке sql находятся: код базы данных, аналитические запросы на выявления ошибок(скопируйте код без комментариев) и аналитические запросы на выборку данных(также скопируйте без комментариев)

в папке docs находятся: er диаграмма показывающая связь таблиц и  документ-паспорт проекта с подробный разъяснением и отчетом

в папке exel находятся результаты аналитических запросов на выборку данных

в папке presentation находится презентация для выступления и защиты проекта
